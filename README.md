# ДЗ 3. Docker

В этом задании нужно было запустить приложение со счётчиком через Docker. Для хранения данных я использовал Redis. Само приложение не менял.

## Запуск

Сначала создаём `.env`:

`cp .env.example .env`

Запускаем контейнеры:

`docker compose up -d --build`

Проверяем, что всё запустилось:

`docker compose ps`

Проверить счётчик можно командами:

- `curl http://localhost:8080/`
- `curl -X POST http://localhost:8080/increment`

## Настройки

В `.env` можно изменить две переменные:

- `HOST_PORT` — порт, по умолчанию 8080.
- `GREETING` — текст приветствия.

Само приложение работает на порту 8000 внутри контейнера.

## Redis

Данные счётчика хранятся в Redis. Для него создан volume `redis_data`.

Если удалить контейнеры через `docker compose down`, данные останутся. После повторного запуска счётчик продолжит работать с прежнего значения.

## Проверка

Для проверки сделал скрипт `scripts/check.sh`.

Запуск:

`chmod +x scripts/check.sh`

`./scripts/check.sh`

Скрипт проверяет счётчик, пересоздание контейнера, отключение Redis и его восстановление. Ещё он делает резервную копию данных.

Результаты двух запусков сохранил в `tests/run1.txt` и `tests/run2.txt`.

## Остановка

`docker compose down`
