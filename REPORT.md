# Отчёт по ДЗ 3

## 1. Docker

Сначала написал Dockerfile и собрал образ командой:

`docker build -t myapp .`

Потом запустил контейнер на порту 8080. Передал приветствие через переменную `GREETING`.

Проверил счётчик через curl. После двух POST-запросов значение увеличилось с 0 до 2.

Также посмотрел логи через `docker logs mycontainer`.

## 2. Docker Compose

Сделал `compose.yaml` и добавил volume для SQLite.

Запустил приложение, два раза увеличил счётчик. После этого выполнил `docker compose down` и `docker compose up -d`.

Счётчик остался равным 2, то есть данные сохранились.

## 3. Redis

Добавил второй сервис Redis и переключил приложение на него.

Проверил сохранение данных после пересоздания контейнеров. Значение счётчика осталось равным 2.

Потом остановил Redis командой:

`docker compose stop redis`

Получил такие результаты:

- `GET /healthz` — 200
- `GET /readyz` — 503
- `POST /increment` — 503

После `docker compose start redis` приложение снова заработало без перезапуска. Счётчик сначала показывал 2, а после следующего POST стал равен 3.

## 4. Ограничения

Добавил ограничения для приложения:

- UID = 1000
- Память — 256 MiB
- CPU — 1 ядро
- Файловая система только для чтения

Проверил через `docker inspect` и `docker compose exec`.

При попытке создать файл `/test` появилась ошибка `Read-only file system`, как и должно быть.

## 5. Скрипт

Написал `scripts/check.sh` для автоматической проверки.

Скрипт создаёт отдельный проект, проверяет счётчик, пересоздаёт приложение, останавливает и запускает Redis, а также сохраняет резервную копию.

Запустил его два раза подряд. Оба раза получил:

`ALL CHECKS PASSED`

Полный вывод находится в файлах:

- `tests/run1.txt`
- `tests/run2.txt`

Оба запуска прошли без ошибок.
